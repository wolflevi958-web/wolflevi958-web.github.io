ClipperBot YouTube

A private publishing tool for short videos.

ClipperBot YouTube is a small desktop tool that runs on its operator's own computer. It uploads short videos (YouTube Shorts) that the operator has edited and selected to YouTube channels that the operator owns or manages.

How it works

  • The operator connects a YouTube channel once through Google's own sign-in and consent screen. The tool only asks for permission to upload videos (https://www.googleapis.com/auth/youtube.upload).
  • Before every upload the tool shows the destination, the video file, the title, the description and the hashtags. Nothing is uploaded until the operator types ja ("yes") to confirm that specific upload.
  • After an upload, the tool keeps the video ID and link on the operator's computer, so the same video is never uploaded twice.

The tool is not a public service. It has no user accounts, no server and no advertising. It does not read, analyse or change anything else on a YouTube channel.
