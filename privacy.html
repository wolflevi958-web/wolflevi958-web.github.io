Privacy Policy

ClipperBot YouTube · Effective 31 October 2026

This policy explains what ClipperBot YouTube ("the app") does with data it receives from Google, including YouTube. The app is a desktop tool that runs only on its operator's own computer. It has no servers of its own.

1. Data the app accesses

The app requests a single Google OAuth scope: https://www.googleapis.com/auth/youtube.upload. With it, the app can upload videos to the YouTube channel that was chosen on Google's consent screen. The app does not request and cannot access your email address, contacts, viewing history, comments, analytics, subscribers or any other Google account data.

When Google confirms an upload, the response contains the new video's ID, the channel ID, and the video's privacy and upload status. The app reads these fields.

2. How the data is used

  • The OAuth tokens are used only to upload videos that the operator has selected and confirmed one at a time.
  • The video ID, link and channel ID are used to show the operator where the video went, to check that it reached the intended channel, and to prevent the same video from being uploaded twice.

The app does not use Google user data for advertising, profiling, selling or any other purpose, and it does not use that data to develop or train artificial intelligence or machine-learning models.

3. Storage and security

  • The OAuth refresh token is stored only on the operator's computer, in a private folder outside the app's code (folder permissions 0700, file permissions 0600). It is never put in source control and is never shown on screen.
  • The video ID, link and upload status are stored in a local database on the same computer.
  • Data travels only between the operator's computer and Google's servers over HTTPS.

4. Sharing

The app does not share, sell, rent or transfer Google user data to anyone. The only recipient of the data is Google itself, through the YouTube Data API.

5. Retention and deletion

  • A token is kept until the channel is disconnected. Deleting the token file on the operator's computer removes it from the app immediately.
  • You can revoke the app's access at any time at myaccount.google.com/permissions. While the app is in Google's "Testing" mode, tokens also expire automatically after 7 days.
  • Local records of uploads (video ID and link) are kept so that duplicate uploads can be prevented. They are deleted on request.
  • Videos on YouTube are managed in YouTube Studio and are not deleted by the app.

6. Google API Services User Data Policy

ClipperBot YouTube's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. YouTube API Services

The app uses YouTube API Services. By connecting a channel you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

8. This website

This website is hosted on GitHub Pages. It uses no cookies, analytics or trackers of its own. GitHub may log technical data such as IP addresses; see the GitHub Privacy Statement.

9. Changes

If this policy changes, the new version will be published on this page with a new effective date.
